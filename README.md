# Apoorva Trivedi — Portfolio

A responsive, dark, modern developer portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive styling, animations and visual system
- `script.js` — mobile navigation and reveal animations
- `Apoorva_Trivedi_Resume.pdf` — add your PDF resume here before deploying

## Before deployment
1. Replace any project GitHub links with the exact repository URLs.
2. Add your latest PDF resume as `Apoorva_Trivedi_Resume.pdf`.
3. Check your LinkedIn URL and email.
4. Deploy the folder to GitHub Pages, Netlify or Vercel.

## Local preview
Open `index.html` directly in a browser, or run a simple local server:
`python -m http.server 8000`
